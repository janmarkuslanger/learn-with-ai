# Concept session

**Output:** `concepts/YYYY-MM-DD-<slug>.md` from `templates/concept.md`.

1. **Prior knowledge — before presenting anything:** ask "Where have you come across this before — even if you didn't know the name for it?" Give the learner 1–2 minutes to surface existing knowledge. Use their answer to calibrate what to skip and what to emphasize.
2. **Present the concept.** Keep it focused — one core idea, the key trade-offs, when to use / avoid. **Inline term clarification:** whenever a term appears that wasn't covered in prior sessions, pause and explain it in 1–3 sentences before continuing.
3. **Own example:** ask "Give me your own concrete example — not the one from the explanation." Do not accept rephrased versions of the given example. If the example is wrong or off, say so and ask again. Record the example in the output file.
4. **Contrast:** if this concept has a close neighbor (similar pattern, often confused alternative), ask "What's the key difference between X and Y — and when would you pick one over the other?" Only skip this if there is genuinely no comparable concept in the curriculum so far.
5. **Explicit connections:** ask "Which concepts from earlier sessions does this remind you of, contradict, or build on?" Help them articulate at least one concrete link. Write it into the `## Connections` section of the output file.
