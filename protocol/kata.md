# Kata session

**Output:** `katas/YYYY-MM-DD-<slug>.md` from `templates/kata.md`.

Run the prerequisite check before designing the scenario; simple side-concepts go into `## Side-topic notes` before the task.

- Give a concrete scenario with constraints. Do not solve it for them. Ask guiding questions if stuck.
- **Feynman check** after the kata: "Now explain the core concept behind this kata in 2–3 sentences, as if you're talking to a junior developer." If the explanation is vague or missing key parts, probe further. Do not move on until the explanation is solid.
