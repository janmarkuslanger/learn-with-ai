# Mixed session

**Output:** the concept file (`concepts/YYYY-MM-DD-<slug>.md`); the gap sprint is logged in the session log only.

Triggered by `AGENTS.md` Step 1 (`Consecutive reviews ≥ 3`, M/L only). Goal: break the review loop by combining a targeted gap sprint with new content — the learner always leaves with something genuinely new.

Structure (in this order — do not swap):

1. **Gap sprint:** pick the single most urgent open gap from the gap tracker (`Reviews since last seen` highest, or longest overdue SRS topic). Ask exactly **2 questions** on it, with full error analysis. Do not run more than 2 questions — the point is to stay accountable to open gaps without getting stuck in review again.
2. **New topic introduction:** immediately after the gap sprint, move to the next topic in the curriculum and run `protocol/concept.md` steps 1–4 (prior knowledge, presentation, own example, contrast). Skip the connections step — that can happen in a dedicated follow-up.
3. **Tracking:** log the gap sprint and the new concept as a single session-log entry (`Type: mixed`).
